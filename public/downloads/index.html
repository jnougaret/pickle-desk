Install for offline use

While online, open Pickle Desk, install it using the steps below, and open the new icon once. Then you can use it in Airplane Mode. The Web app saves tournaments in this browser profile, so export a .tournament backup before switching devices or versions.

iOS (iPhone)

Safari

Open Pickle Desk in Safari. Tap Share → Add to Home Screen, turn on Open as Web App, then tap Add.

Chrome

Open Pickle Desk in Chrome. Tap Share beside the address bar, then Add to Home Screen → Add. iPhone Chrome uses the Share menu; it does not use Android’s Install app menu.

Android

Chrome

Open Pickle Desk in Chrome. Tap ⋮ → Install app and confirm. If Chrome shows Add to home screen → Create shortcut instead, tap Add, then open the new icon once before going offline.

iPadOS (iPad)

Safari

Open Pickle Desk in Safari. Tap Share → More → Add to Home Screen, turn on Open as Web App, then tap Add.

Chrome

Open Pickle Desk in Chrome. Tap Share beside the address bar, then Add to Home Screen → Add.

macOS

Chrome Web app

Open Pickle Desk in Chrome. Choose ⋮ → Cast, save, and share → Install page as app (or use the install icon in the address bar), then open it once from Applications or the Dock.

Safari Web app

On macOS Sonoma 14 or later, open Pickle Desk in Safari and choose File → Add to Dock, then Add.

Native desktop app

For the DMG above, drag Pickle Desk to Applications. If macOS blocks the first launch, Control-click the app and choose Open, or use System Settings → Privacy & Security → Open Anyway. Only approve the official download.

Windows

Chrome Web app

Open Pickle Desk in Chrome. Choose ⋮ → Cast, save, and share → Install page as app (or use the install icon in the address bar), then open it once from the desktop or Start menu.

Native desktop app

For the EXE above, run the installer. If SmartScreen says Windows protected your PC, choose More info → Run anyway. The Microsoft Store link avoids the unsigned-installer warning. Only approve the official download.
